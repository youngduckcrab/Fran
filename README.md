# Fran

둘만 쓰는 메신저. 각자 자기 언어로 쓰면, Claude가 **앞뒤 대화를 읽고** 상대의 언어로 옮겨 준다.

한국어로 보낸 `"오늘 좀 그랬어… ㅠㅠ"` 가 스페인어 쪽에 `"Hoy fue un día raro… buaa"` 로 도착하는 것이 목표다.
사전적으로 맞는 번역이 아니라, **그 사람이 그 언어로 말했다면 했을 법한 문장**을 만드는 데 초점을 둔다.

기본 설정은 **Gemini 무료 티어**라 돈을 내지 않고 시작할 수 있다.

- 한국어 ↔ 스페인어가 기본, 공부 중인 **영어·중국어**도 함께 받아볼 수 있다
- 말풍선을 누르면 원문과 다른 언어 번역이 함께 펼쳐진다
- 두 사람의 **성별과 사는 곳** 을 번역이 안다 — `cansado/cansada` 가 맞고, 칠레 말로 간다
- 번역에 **학습용 메모**(관용구·슬랭·놓친 뉘앙스)가 0~2개 붙는다
- 말풍선을 **길게 누르면 설명** — 단어별 뜻, 문법, 이렇게 답하면 된다는 예시까지
- **단어 선택** 으로 문장의 단어를 하나씩 눌러 뜻을 보고, 그 자리에서 단어장에 담기
- **번역만 / 원문+번역 / 원문만** 중에 골라서 본다
- 보낸 글을 **고칠 수 있다.** 고치면 번역도 다시 돌아간다
- **화면 문구가 사람마다 자기 언어로** 나온다. 각자 자기 주소로 들어간다
- **용어집**에 애칭을 미리 정해둔다. "`애기`는 `bebe` 로, `amor` 로는 쓰지 말 것"
- 이번 메시지만 다르게 옮기고 싶으면 **✎ 로 지시**를 붙인다. 상대에게는 보이지 않는다
- 계정은 두 개뿐. 회원가입도 친구 추가도 없다

## 빠르게 실행하기

```bash
git clone https://github.com/youngduckcrab/Fran.git
cd Fran
npm install                 # shared 패키지까지 자동으로 빌드된다

cp .env.example .env        # 아래 설명대로 채운다
npm run dev                 # 서버 :8787 + 웹 :5173
```

브라우저에서 <http://localhost:5173> 를 열고, `.env` 에 적어둔 패스코드로 로그인한다.

> `.env` 는 **저장소 루트**에 둔다. 서버가 자기 위치를 기준으로 찾으므로 어느 디렉터리에서
> 실행하든 상관없다.

### 혼자서 두 사람 몫을 테스트하려면

로그인 토큰이 브라우저의 `localStorage` 에 저장되기 때문에, 같은 브라우저의 탭 두 개로는
두 사람을 동시에 로그인시킬 수 없다. **일반 창 + 시크릿 창**(또는 다른 브라우저)을 쓰면
양쪽에서 메시지가 오가는 걸 바로 볼 수 있다.

### 폰에서 열어보기

개발 서버와 빌드본 모두 모든 네트워크 인터페이스에 바인딩하므로, **같은 와이파이에 있는
폰이면 컴퓨터 IP로 바로 접속된다.**

```bash
# 컴퓨터 IP 확인
ipconfig getifaddr en0        # macOS
hostname -I                   # Linux
ipconfig                      # Windows (IPv4 주소)
```

| 실행 방식 | 폰에서 열 주소 |
| --- | --- |
| `npm run dev` | `http://<컴퓨터IP>:5173` |
| `npm run build && npm start` | `http://<컴퓨터IP>:8787` |

`npm run dev` 로 띄우면 Vite 가 터미널에 `Network:` 주소를 직접 알려준다.

안 열리면 대개 컴퓨터 방화벽이다. macOS는 시스템 설정 → 네트워크 → 방화벽,
Windows는 첫 실행 때 뜨는 "네트워크 액세스 허용" 대화상자를 확인할 것.

**홈 화면에 추가**해서 앱처럼 쓰는 것까지는 이 상태로도 된다. 다만 서비스 워커
(오프라인 캐시)는 HTTPS 에서만 동작하므로, PWA 를 제대로 확인하려면 아래 터널이 필요하다.

### 컴퓨터가 없다면

폰만 있어도 된다. 두 가지 길이 있다.

**1. GitHub Codespaces — 지금 당장 보고 싶을 때**

저장소 페이지에서 `Code` → `Codespaces` → `Create codespace`. 클라우드에 개발 환경이
뜨고 폰 브라우저에서 그대로 쓸 수 있다. `.devcontainer/` 설정이 있어서 `npm install` 까지
자동으로 돌아간다.

```bash
# Codespaces 터미널에서
cp .env.example .env     # 편집기로 GEMINI_API_KEY, AUTH_SECRET, 패스코드 채우기
npm run dev
```

포트 5173 이 자동으로 **공개 https 주소**로 열린다(`.devcontainer` 에 설정해 두었다).
그 주소를 폰 브라우저에서 열면 끝이고, 칠레의 Fran 도 같은 주소로 들어올 수 있다.
https 라서 PWA(홈 화면에 추가, 오프라인 캐시)도 제대로 동작한다.

`npm run dev` 는 실행 전에 두 가지를 알아서 한다.

- **5173·8787 을 붙잡고 있는 이전 프로세스를 정리한다.** `Ctrl+C` 가 제대로 안 먹어도
  그냥 다시 실행하면 된다
- **포트를 공개로 열고 접속 주소를 터미널에 찍는다.** 포트가 Private 이면 GitHub 에
  로그인되지 않은 브라우저(대개 폰)는 404 를 받는데, 증상만 봐서는 서버가 죽은 것과
  구분되지 않는다. 자동으로 열지 못하면 무엇을 눌러야 하는지 안내한다

```
[share] 포트 5173 을 공개로 열었습니다.
[share] 폰이나 상대방은 이 주소로 접속하세요:

    https://<코드스페이스이름>-5173.app.github.dev
```

포트만 따로 열고 싶으면 `npm run share`.

> 주소가 공개이므로 **패스코드가 유일한 자물쇠**다. 예시 값 그대로면 서버가 시작할 때
> 경고하고 바꾸는 명령까지 알려준다.

끄면 사라지는 임시 환경이고 무료 사용 시간에 한도가 있으니, 계속 쓸 거라면 아래 배포로.

**2. 배포 — 계속 쓸 때 (권장)**

한 번 올려두면 터미널도 Codespaces 도 다시 볼 일이 없다. 주소 하나만 남고, 두 사람 다
그냥 접속해서 쓰면 된다. 코드를 고칠 일이 생기면 저장소에 푸시하는 것만으로 다시 배포된다.

준비물은 두 가지다.

**① 무료 Postgres** — [Neon](https://neon.tech) 이나 [Supabase](https://supabase.com) 에서
프로젝트를 하나 만들면 연결 문자열(`postgresql://...`)을 준다. 대화가 여기 저장되므로
서버가 재시작되거나 다시 배포돼도 기록이 남는다.

**② 호스팅** — 이 저장소를 GitHub 에서 바로 배포할 수 있는 곳이면 어디든 된다
(Render, Railway, Koyeb 등). `Dockerfile` 이 있으므로 Docker 배포도 되고, 아니면 이 두 줄만
설정하면 된다.

| 설정 | 값 |
| --- | --- |
| Build command | `npm ci && npm run build` |
| Start command | `npm start` |
| Health check | `/healthz` |

**환경변수**는 `.env.example` 의 항목을 호스팅 대시보드에 그대로 넣는다. 최소한 이 넷:

```
DATABASE_URL     ①에서 받은 연결 문자열
GEMINI_API_KEY   aistudio.google.com/apikey
AUTH_SECRET      긴 랜덤 문자열
USER_A_PASSCODE / USER_B_PASSCODE   두 사람의 패스코드 (꼭 바꿀 것)
```

`PORT` 는 호스팅이 알아서 넣어 준다. 디스크나 볼륨은 필요 없다.

> 고를 때 확인할 것: **WebSocket 지원**(실시간 메시지에 필요)과 **무료 등급의 휴면 정책**.
> 무료 등급은 한동안 안 쓰면 잠들었다가 첫 접속이 느린 경우가 많다. 대화가 사라지지는
> 않지만 첫 메시지가 늦게 도착한다.

**잠든 서버를 기다리는 동안** — 앱은 마지막으로 본 대화를 이 기기에 적어 두고, 열자마자
그걸 먼저 그린다. 서버가 깨어나는 30초 동안에도 어제 나눈 말을 읽을 수 있고, 연결되면
조용히 최신으로 바뀐다. 머리말의 `연결 중…` 이 아직 서버를 기다리는 중이라는 뜻이다.

그래도 **새 메시지를 보내려면 서버가 깨어나야 한다.** 이 기다림 자체를 없애려면
호스팅에서 유료 등급으로 올리거나, 밖에서 몇 분마다 `/healthz` 를 한 번씩 찔러
재워두지 않는 방법이 있다(무료 등급의 월 사용 시간을 대신 쓰게 된다).

### 상대와 함께 테스트하기 (다른 나라)

로컬 주소로는 접속할 수 없으니 둘 중 하나가 필요하다.

- **터널링** — ngrok, cloudflared 같은 도구로 로컬 서버에 임시 https 주소를 붙인다.
  개발 서버에 붙일 때는 Vite 가 낯선 도메인을 막으므로 도메인을 알려줘야 한다:

  ```bash
  VITE_ALLOWED_HOSTS=abc-123.ngrok-free.app npm run dev
  ```

- **배포** — `npm run build` 후 `npm start` 하나면 API·WebSocket·웹이 전부 한 프로세스에서
  서빙된다. Node 가 도는 곳이면 어디든 올릴 수 있다. HTTPS 뒤에 두면 PWA 설치도 정상 동작한다.

### .env 채우기

| 항목 | 설명 |
| --- | --- |
| `GEMINI_API_KEY` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 발급. **무료 티어로 시작한다** |
| `AUTH_SECRET` | 로그인 토큰 서명용. `openssl rand -hex 32` 로 만들면 된다 |
| `USER_A_*`, `USER_B_*` | 두 사람의 이름·기본 언어·패스코드. 패스코드는 서로 다르게 |
| `USER_*_GENDER`, `USER_*_REGION` | 번역에 쓰인다. 아래 "성별과 사는 곳" 참고. 없어도 된다 |
| `GEMINI_MODEL` | 기본 `gemini-flash-lite-latest` (무료 한도가 가장 넉넉) |
| `TRANSLATION_CONTEXT_SIZE` | 번역할 때 참고할 직전 메시지 수. 기본 12 |

키가 없어도 서버는 뜬다. 메시지는 정상적으로 오가고 번역만 실패한다.

**모델 이름이 맞는지 확인하려면:**

```bash
npm run models --workspace=server     # 내 키로 쓸 수 있는 모델 목록
```

무료 티어에서 쓸 수 있는 모델과 한도는 수시로 바뀌므로, `GEMINI_MODEL` 을 정하기 전에
한 번 돌려보는 편이 확실하다. 현재 한도는 [AI Studio](https://aistudio.google.com) 에서 확인할 것.

**키를 넣은 직후에는 이것부터:**

```bash
npm run try-translate --workspace=server
```

채팅을 띄우지 않고 번역 한 건만 돌려본다. 맥락이 있어야만 풀리는 문장("걔"가 누구인지
앞 대화에만 있다)을 넣어두었으므로, 결과가 제대로 나오면 맥락 번역이 동작하는 것이다.
실패하면 무엇을 해야 하는지까지 화면에 찍힌다.

> 실패했을 때 마지막에 붙는 `npm error ...` 블록은 npm 이 덧붙이는 것이니 무시하고,
> 그 위의 `✗` 로 시작하는 줄을 보면 된다.

### 성별과 사는 곳

스페인어는 **말하는 사람과 듣는 사람의 성에 따라 말이 달라진다.** "피곤해" 는 쓴 사람이
남자면 `estoy cansado`, 여자면 `estoy cansada` 다. "예쁘다" 는 듣는 사람 쪽을 따라간다.
한국어에는 이 단서가 아예 없어서, 모르면 모델이 기본값(대개 남성형)으로 찍는다.

사는 곳도 마찬가지다. 같은 스페인어라도 **칠레에서 쓰는 말과 스페인에서 쓰는 말이 다르다.**
알려주지 않으면 교과서 스페인어나 `vosotros`, `vale` 같은 스페인 쪽 말이 섞여 나온다.

두 가지 방법이 있고, **앱에서 고른 것이 `.env` 를 이긴다.**

- **앱에서** — 설정 → **나에 대해**. 각자 자기 것을 고른다. 서버를 다시 띄울 필요가 없다.
- **`.env` 에서** — 두 사람 것을 한 번에. 호스팅에 올렸다면 대시보드의 환경변수에 넣는다.

```bash
USER_A_GENDER=male        # female | male | unspecified
USER_A_REGION=한국
USER_B_GENDER=female
USER_B_REGION=Chile
```

둘 다 비워 두어도 앱은 그대로 돈다. 번역이 그만큼 뭉뚱그려질 뿐이고, 성을 모를 때는
찍는 대신 성이 드러나지 않게 돌려 쓰라고 모델에 일러둔다.

### 번역 provider 바꾸기

번역기는 provider 어댑터로 분리돼 있다. `.env` 의 `TRANSLATION_PROVIDER` 한 줄로 갈아끼운다.

| provider | 비용 | 비고 |
| --- | --- | --- |
| `gemini` (기본) | 무료 티어 | 한도가 있고, 무료 티어는 보통 입력 데이터가 모델 개선에 쓰인다 |
| `claude` | 유료 (API 크레딧) | Claude 구독(Pro/Max)과는 **별개로 과금된다** |

> ⚠️ **사적인 대화라는 점을 한 번 생각해볼 것.** 무료 티어는 대개 입력 데이터를 서비스 개선에
> 활용할 수 있다는 조건이 붙는다. 가입할 때 데이터 정책을 직접 확인하고, 마음에 걸리면
> 유료 티어나 `claude` provider로 바꾸면 된다.

### 배포

```bash
npm run build     # shared → server → web 순서로 빌드
npm start         # :8787 하나로 API + WebSocket + 웹까지 전부 서빙
```

`server/dist/index.js` 는 `web/dist` 가 있으면 그것도 같이 정적 서빙한다. 즉 배포는 **프로세스 하나**면 된다.
HTTPS 뒤에 두면 폰에서 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치된다(PWA).

> 둘만 쓰는 앱이라 인증은 사람당 패스코드 하나 + 서명 토큰으로 끝낸다.
> 공개 인터넷에 올린다면 HTTPS는 필수이고, 패스코드는 길고 추측하기 어려운 것으로 잡을 것.

## 비밀번호 바꾸기

설정 → **비밀번호** 에서 지금 비밀번호와 새 비밀번호를 넣으면 바로 바뀐다. `.env` 를
고치거나 서버를 다시 켤 필요 없다. 새 비밀번호는 **두 번 적는다** — 오타가 그대로 잠금이
되면 둘 다 못 들어온다. 두 값이 다르면 바꾸기 버튼이 눌리지 않는다.

- 바꾼 비밀번호는 **해시(scrypt)로만** 저장된다. DB 를 들여다봐도 원래 값은 알 수 없다.
- **바꾸면 다른 기기는 로그아웃된다.** 바꾸는 이유가 대개 "누가 아는 것 같다"인데, 이미
  들어와 있는 쪽이 그대로 남으면 바꾼 의미가 없다. 바꾼 기기만 로그인이 유지된다.
- 한 번도 바꾸지 않았다면 `.env` 의 `USER_A_PASSCODE` / `USER_B_PASSCODE` 를 쓴다.
  한 번 바꾸고 나면 그 값은 더 이상 쓰이지 않는다(그 사람에 한해서).
- 상대의 비밀번호에는 영향이 없다.

## 각자의 주소

주소 끝에 누구인지를 붙이면 그 사람의 앱으로 열린다. 이름을 고를 필요 없이 바로 자기
화면이 뜨고, 화면 문구도 그 사람의 언어로 나온다.

```
https://<주소>/?u=me      ← 승윤 (한국어 화면)
https://<주소>/?u=fran    ← Fran (스페인어 화면)
```

`?u=` 의 값은 `.env` 의 `USER_A_ID` / `USER_B_ID` 다. 각자 자기 링크를 홈 화면에 추가하면
서로 다른 앱처럼 쓸 수 있다.

로그인 상태도 사람마다 따로 기억하므로, **한 브라우저에서 두 창을 각자의 주소로 열어도
서로 다른 사람으로 로그인된 채 유지된다.**

주소가 누구인지 말해 주므로 **고르는 화면을 띄우지 않는다.** 이름 대신 "Fran 으로
들어갑니다"라고만 알려주고 비밀번호만 받는다. 주소에 `?u=` 가 없거나 없는 이름이면
예전처럼 두 사람 중에서 고르는 화면이 나온다.

**화면 언어는 "내가 받아볼 언어"의 첫 번째를 따라간다.** 설정에서 바꾸면 화면도 함께 바뀐다.
한국어·스페인어·영어를 지원하고, 그 밖의 경우에는 영어로 나온다.

번역 실패 같은 서버 쪽 사유도 문구가 아니라 코드로 전달해서, 읽는 사람의 언어로 보여준다.

## 각자 앱으로 설치하기

자기 주소로 들어간 다음 브라우저 메뉴에서 **"홈 화면에 추가"**(iOS Safari) 또는
**"앱 설치"**(Android Chrome) 를 누르면 각자의 앱이 따로 깔린다.

```
https://<주소>/?u=me      ← 승윤 폰에 설치할 링크
https://<주소>/?u=fran    ← Fran 폰에 설치할 링크
```

설치된 앱은 **상대의 이름**을 달고 있다. 승윤 폰에는 `Fran`, Fran 폰에는 `승윤` 이 뜬다.
자기 이름이 적힌 아이콘을 누르는 것보다 그 편이 자연스럽다. 앱을 열면 `?u=` 가 붙은
자기 주소로 바로 들어가므로, 설치한 뒤에는 누구인지 다시 고를 일이 없다.

이름과 시작 주소는 서버가 `/manifest.webmanifest?u=<아이디>` 로 그때그때 만들어 준다.
`.env` 에서 이름을 바꾸면 다음에 설치할 때부터 반영된다.

## 내 말이 상대에게 어떻게 갔는지

내가 보낸 말풍선 안에 **상대가 실제로 읽은 문장**이 함께 보인다.

```
안녕 애기
─────────────────
Fran 에게는 이렇게 갔어요
Hola bebé
```

번역기를 거쳐 말하는 사이에서는 "내 말이 저쪽에 어떻게 도착했나"가 가장 궁금한 부분이고,
서로의 언어를 배우려고 만든 앱이니 기본은 펼쳐 둔다. 상대 화면에는 뜨지 않는다.
번역 결과가 마음에 안 들면 그 자리에서 길게 눌러 다시 번역하거나 코멘트를 붙이면 된다.

**내 말풍선을 누르면 번역이 접히고, 다시 누르면 펴진다.** 말풍선마다 따로라서, 지금 안 보고
싶은 것만 접어 두면 된다. (`Fran 에게는 이렇게 갔어요 ▾` 줄을 눌러도 같다.)

## 소리로 들어보기

**줄마다 붙은 ▶** 를 누르면 그 줄을 읽어준다. 글로 봐서는 발음을 모를 수 있어서 넣었다.

- **번역문 옆 ▶** — 내 언어로 어떻게 읽는지. 한국어 번역이면 한국어로 들린다.
- **원문 옆 ▶** — 상대가 실제로 한 말. Fran 의 스페인어는 스페인어로 들린다.
  원문 줄이 접혀 있을 때는 시각 옆에 ▶ 가 남아 있어서, 펼치지 않고도 들을 수 있다.
- **내가 보낸 말**은 "이렇게 갔어요" 안의 번역문을 읽어준다. 상대가 듣게 될 문장이다.
- 듣는 중에 다시 누르면 멈춘다. 다른 걸 누르면 앞의 소리는 끊긴다.
- 저장한 문장도 두 줄 모두 ▶ 로 들을 수 있다.

**이모지는 읽지 않는다.** 그대로 넘기면 합성기가 "빨간 하트", "기뻐서 우는 얼굴" 하고
이름을 읽어 버린다. 발음이 궁금해서 누른 건데 엉뚱한 말이 끼어드는 셈이라, 글만 골라
넘긴다. `ㅋㅋ` `ㅎㅎ` `ㅠㅠ` 처럼 낱자만 늘어놓은 것도 마찬가지다 — 글자가 아니라 표정인데
합성기는 낱자 이름("키읔")을 읽으려 든다.

```
Te extraño mucho ❤️😭   →   "Te extraño mucho"
오늘 재밌었어 ㅋㅋㅋ        →   "오늘 재밌었어"
```

이모지만 있는 말(`❤️😂`)에는 읽어 줄 것이 없으므로 **▶ 가 아예 뜨지 않는다.**

목소리는 폰에 깔린 것을 쓴다(브라우저의 음성 합성 기능). 따로 켤 것도, 돈 드는 것도 없다.
스페인어는 **칠레·중남미 목소리를 먼저** 찾는다. 스페인 억양으로 익혀 두면 정작 들을 일이
있는 발음과 어긋나서다. 그 언어 목소리가 기기에 없으면 "이 기기에 Español 목소리가 없어요"
라고 알려준다 — 폰 설정에서 그 언어 음성을 받으면 바로 된다. 음성 기능이 없는 브라우저에서는
▶ 자체가 뜨지 않는다.

## 메인 화면

로그인하면 먼저 뜨는 화면. 여기서 네 군데로 갈라진다.

```
┌──────────────────────────────┐
│ Fran                    설정 │
│ 접속 중                      │
│ ┌──────────────────────────┐ │
│ │ 💬 채팅                ② │ │  ← 마지막 한 줄과 안 읽은 개수
│ │    오늘 뭐 했어?          │ │
│ └──────────────────────────┘ │
│ ┌────┐ ┌────┐ ┌────┐        │
│ │ ⭐  │ │ 📓 │ │ 🖼  │        │
│ │저장한│ │단어장│ │사진첩│        │
│ │ 문장 │ │    │ │    │        │
│ └────┘ └────┘ └────┘        │
└──────────────────────────────┘
```

채팅을 보고 있지 않을 때 온 메시지는 채팅 칸에 **개수**로 뜨고, 채팅을 열면 사라진다.
이 숫자는 서버가 기억해서 **앱을 껐다 켜도, 폰과 컴퓨터 어디서 봐도 같다.** 알림을 켜 두면
홈 화면 아이콘에도 같은 숫자가 붙는다(지원하는 기기에서).

## 읽음 표시

내가 보낸 말풍선의 시각 옆에 체크가 붙는다.

- **✓ 하나(흐림)** — 보냈다. 상대는 아직 안 봤다.
- **✓✓ 둘(색깔)** — 상대가 읽었다.

상대가 **앱을 열어 채팅을 보고 있을 때만** 읽은 것으로 친다. 알림만 온 상태나, 앱이 켜져
있어도 화면이 가려져 있으면(다른 앱을 보는 중, 주머니 속) 아직 안 읽은 것이다.

## 사진과 음성 메시지

입력칸 왼쪽의 **+** 를 누르면 사진·녹음·번역 지시가 펼쳐진다.

- 사진은 **보내기 전에 긴 변 1600px, JPEG 로 줄여서** 올라간다. 폰 사진 한 장이 5MB 씩 하는데
  그대로 쌓으면 무료 DB 용량이 금방 차고, 상대도 데이터를 써 가며 받아야 한다.
- 녹음은 누르면 바로 시작하고, 흐른 시간이 보인다. **멈추고 보내기** 를 누르면 준비되고,
  **취소** 를 누르면 버린다. 마이크는 어느 쪽이든 바로 꺼진다.
- 보낸 음성은 **뭐라고 말했는지 글로 옮겨지고, 그 글이 평소처럼 번역된다.** 상대 화면에는
  자기 언어로 뜨고 그 아래에 "받아쓴 글"로 원래 말이 붙는다. 들으면서 읽으면 발음이 붙는다.
- 사진·음성에 글을 같이 붙여 보낼 수 있고, 그 글은 평소처럼 번역된다.
- 녹음 버튼은 **https 에서만** 보인다. 브라우저가 마이크를 그 경우에만 내주기 때문이다.

사진을 누르면 앱 안에서 크게 보인다. 바깥을 누르거나 뒤로가기로 닫는다.
크게 본 화면의 **저장** 을 누르면 폰에 저장된다 — 아이폰·안드로이드에서는 공유 창이 떠서
사진 앱에 넣을 수 있고, 컴퓨터에서는 그냥 내려받는다.
주고받은 사진은 **사진첩** 에 모인다.

## 저장한 문장과 단어장

**문장**은 말풍선을 길게 눌러 → **이 문장 저장**. 그러면 **원문과 번역문이 나란히 뜨고,
그중에서 고른다.** 스페인어를 공부하려면 스페인어 쪽을, 뜻만 남기려면 한국어 쪽을 담으면
된다. 여러 개 골라도 되고, 이미 담은 것은 체크로 표시된다. **잘못 담았으면 다시 눌러 취소**
하면 된다. 보관함도 단어장처럼 **언어별로 나뉜다.** 저장할 때의 문장을 그대로 적어
두므로 나중에 번역을 다시 돌려도 저장해 둔 문장은 바뀌지 않는다. 짝이 되는 문장도 함께
보관해서, 보관함에서 뜻을 같이 볼 수 있다.

**단어**를 담는 길은 두 가지다.

**① 단어를 눌러서** — 말풍선을 길게 눌러 → **단어 선택**. 문장이 그대로 뜨는데 단어마다
누를 수 있다. 모르는 단어를 누르면 그 단어만 짧게 풀어 준다.

```
  Ayer  fui  al  [mercado]  y  me  acordé  de  ti.
  ‥‥‥  ‥‥‥  ‥‥   ‥‥‥‥‥   ‥  ‥‥   ‥‥‥‥  ‥‥  ‥‥

┌ mercado  (명사)  ▶ ────────────┐
│ 시장                            │
│ │ 여기서는 물건을 사러 간 그 시장.  │
│ 칠레에서는 feria 라고도 한다.      │
│      [ + mercado 담기 ]         │
└────────────────────────────────┘
```

**원문이든 번역문이든** 위쪽에서 골라 누를 수 있다(Español / 한국어 / English). 처음에는
공부하는 언어 쪽이 열린다. 담은 단어는 문장에서 밑줄이 진해져서, 어디까지 챙겼는지 보인다.
담을 때는 **사전형**(`fui` → `ir`)으로 들어가고, 이 문장에서 어떻게 쓰였는지가 메모로 붙는다.
같은 문장의 같은 단어는 한 번만 물어보고 그다음부터는 바로 뜬다.

띄어쓰기가 없는 중국어도 단어 단위로 잘린다(`我 昨天 去了 市场`). 사진만 보낸 메시지처럼
글이 없으면 **단어 선택** 은 뜨지 않는다.

**② 설명 화면에서** — 조각 오른쪽의 **+** 를 누르면 담긴다. 문장을 통째로 뜯어보다가
눈에 걸리는 단어를 담는 길이다.

```
┌ ¿Dormiste              [+] ┐
│ 잤어?                       │
│ dormir(자다)의 과거형이에요   │
└────────────────────────────┘
```

담기는 표제어는 **기호를 뗀 것**(`¿Dormiste` → `Dormiste`)이다. 설명은 문장을 잘라서 주기
때문에 조각 끝에 물음표나 쉼표가 붙어 오는데, 그대로 담으면 같은 단어가 여러 줄로 쌓인다.
같은 단어를 또 담으면 줄이 늘지 않고 뜻만 최신으로 바뀐다.

저장한 문장도 단어장도 **사람마다 따로** 쌓인다. 둘 다 ▶ 로 소리를 들을 수 있다.

### 단어장 쓰기

- **언어별로 나뉜다.** 위쪽에서 언어를 고르면 그 언어만 보인다(많이 담은 언어가 앞).
- **외우는 중 / 외웠어요** 두 칸으로 갈라진다. 카드의 `○ 외웠어요로 옮기기` 를 누르면
  넘어가고, 다시 누르면 돌아온다. 같은 단어를 대화에서 또 담아도 외운 표시는 그대로다.
- **예문 보기** 를 누르면 그 단어가 실제로 쓰인 문장을 만들어 준다. 교과서 문장이 아니라
  둘이 주고받을 법한 말로. **`예문 더 만들기` 를 누르면 아래에 하나씩 쌓인다** — 앞의 것은
  지워지지 않는다. 같은 단어가 여러 상황에서 어떻게 쓰이는지가 배울 거리라서.
  이미 있는 문장은 모델에 알려 주고 다른 것을 부탁하며, 그래도 겹치면 몇 번 더 물어본 뒤
  "비슷한 것만 나와요" 라고 알려준다. 예문마다 ▶ 로 들을 수 있고, **책갈피를 누르면
  보관함(저장한 문장)에 담긴다** — 다시 누르면 빠진다. 보관함에서는 어느 단어에서 온
  예문인지(`extrañar · 9/18`) 함께 보인다.

## 반응과 답장

- 말풍선을 **길게 누르면** 맨 위에 이모지 줄(❤️ 😂 👍 😮 🥺 🔥)이 뜬다. 하나를 누르면 말풍선
  아래에 붙고, 같은 걸 다시 누르면 지워진다. 한 사람당 하나씩이다.
- 말풍선을 **오른쪽으로 밀면** 그 메시지에 답장한다. 입력칸 위에 답할 메시지가 뜨고,
  보내면 그 인용이 말풍선에 붙는다. 길게 눌러 `답장하기` 를 골라도 된다.

## 보낸 글 고치기

내 말풍선을 길게 눌러 **수정**. 쓴 글이 입력칸으로 내려오고, 고쳐서 ✓ 를 누르면 저장된다.

고치면 **번역도 다시 돈다.** 옛 번역은 그 자리에서 지워진다 — 원문과 번역이 어긋난 채로
잠깐이라도 남으면 상대가 그 사이에 엉뚱한 말을 읽게 된다. 고친 말풍선에는 시각 옆에
`수정됨` 이 붙어서 상대도 알 수 있다.

내가 보낸 글만, 글이 실제로 달라졌을 때만 고쳐진다. 같은 글로 다시 저장하면 번역을
또 돌리지 않는다(무료 한도를 그냥 깎을 이유가 없다).

## 엔터는 줄바꿈

입력칸에서 **엔터를 치면 줄이 바뀐다.** 보내는 건 오른쪽 종이비행기 버튼이다.
폰에서 쓰는 메신저라, 문단을 나누려다 반쯤 쓴 말이 날아가는 쪽이 더 큰 손해다.
입력칸은 줄 수에 맞춰 늘어난다(화면을 다 덮지 않는 선까지).

## 무엇을 볼지 고르기

설정 → **말풍선에 무엇을 볼까요** 에서 세 가지 중 고른다.

| | 크게 보이는 것 | 말풍선을 누르면 |
| --- | --- | --- |
| **번역만** | 번역문 | 원문이 아래에 붙는다 |
| **원문 + 번역** | 번역문 + 원문 | (그대로) |
| **원문만** | 원문 | 번역문이 아래에 붙는다 |

공부하는 날에는 **원문만** 으로 두고 읽어보다 막힐 때 눌러서 확인하고, 바쁠 때는
**번역만** 으로 둔다. 어느 쪽을 골라도 눌러서 나머지를 볼 수 있다는 건 같다.
고른 것은 이 기기에 남는다(사람마다, 기기마다 따로).

음성 메시지의 받아쓴 글은 어느 쪽에서든 늘 보인다. 뭐라고 말했는지가 이 앱에서 가장
배울 거리가 많은 부분이라서.

## 알림

설정 → **알림** 에서 켠다. 처음 들어오면 홈 화면에서 한 번 물어보고, **나중에**를 누르면
다시 묻지 않는다(설정에서 언제든 켤 수 있다).

메시지가 오면 이렇게 알린다.

| 그때 상태 | 어떻게 알려주나 |
| --- | --- |
| 앱을 보고 있고, 채팅 화면 | 그냥 말풍선이 올라온다 |
| 앱을 보고 있지만 다른 화면(홈·단어장 등) | **화면 위에 한 줄** 이 내려온다. 누르면 채팅으로 |
| 앱은 켜져 있지만 다른 앱을 보는 중 | **폰 알림** |
| 앱을 껐을 때 | **폰 알림** |

- 알림은 **번역이 끝난 뒤** 간다. 받자마자 보내면 상대는 자기가 못 읽는 언어로 된 알림을 받는다.
- 두 번 울리지 않는다. 앱을 보고 있으면 폰 알림 대신 화면 안에서만 알린다.
- 쌓인 알림은 **채팅을 열었을 때** 한꺼번에 치워진다. 앱만 열거나 단어장만 보다 나가면
  그대로 남는다 — 아직 읽지 않았으니까.
- **아이폰은 홈 화면에 추가한 앱에서만** 알림이 온다(iOS 16.4 이상). 사파리 탭으로 열어 두면
  설정에 알림 항목 자체가 뜨지 않는다.
- 알림에 필요한 서명 키는 서버가 처음 켤 때 한 번 만들어 DB 에 넣어 둔다. 따로 설정할 것은 없다.

## 앱 색

설정 → **앱 색** 에서 여섯 가지 중에 고른다(장미·바다·숲·노을·라일락·차분하게).
색 두 개만 바뀌면 배경, 말풍선, 버튼, 강조색까지 전부 그 색으로 따라간다. 사람마다 따로
저장되고, 밝기(밝은 화면/어두운 화면)는 폰 설정을 따라간다.

## 배경화면

설정 → **배경화면** 에서 고른다. 기본 일곱 가지와 **갤러리에서 고르기**(폰에 있는 사진).
대화방 사진을 배경으로 쓰고 싶으면 크게 보기에서 **저장** 한 뒤 갤러리에서 고르면 된다.
사람마다 따로 저장되고, 배경으로 쓰는 사진은 사진첩에는 올라가지 않는다.

## 폰에서 쓸 때

- **뒤로가기 버튼**은 앱을 끄지 않는다. 열린 창을 닫고, 화면에서 홈으로 돌아온다.
  홈에서 한 번 더 누르면 그때 앱이 닫힌다.
- **위에서 아래로 당겨도 새로고침되지 않는다.** 대화 중에 손가락이 조금 미끄러진 것으로
  앱이 통째로 다시 뜨면 곤란해서 막아 뒀다.
- 아이콘은 말풍선 두 개와 하트다. 안드로이드가 동그랗게 잘라내는 경우를 위해 여백을 둔
  아이콘을 따로 넣어 두었다. 모양을 바꾸고 싶으면 `node scripts/make-icons.mjs`.

## 명령어

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 서버와 웹을 동시에 개발 모드로 |
| `npm run dev:server` / `npm run dev:web` | 하나씩 따로 |
| `npm run typecheck` | 전 워크스페이스 타입 검사 |
| `npm run build` | 전체 빌드 |
| `npm start` | 빌드 결과로 실행 |
| `npm run models --workspace=server` | 내 Gemini 키로 쓸 수 있는 모델 목록 |
| `npm run try-translate --workspace=server` | 채팅을 띄우지 않고 번역만 한 번 시험 |

`shared/` 를 고쳤다면 `npm run build --workspace=shared` 를 한 번 돌려야 서버·웹에 반영된다.
