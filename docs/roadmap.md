# 다음에 붙이면 좋을 것들

지금 저장소에 있는 건 "둘이 실제로 쓸 수 있는 최소한"이다. 여기서 뭘 더 할 수 있는지 적어둔다.
순서는 체감 효용 순.

## 곧 아쉬워질 것

- **푸시 알림** — PWA에서도 Web Push로 가능하다(iOS는 16.4+, 홈 화면에 추가한 경우에만).
  `web-push` + 서버에 구독 저장. 이게 없으면 앱을 열어봐야 메시지가 온 걸 안다
- **이미지 전송** — 사진은 장거리 연애에서 텍스트만큼 자주 오간다. 사진에 달린 캡션도 번역 대상
- **읽음 표시** — `read` 이벤트는 프로토콜에 이미 있고 서버가 받기만 한다. 저장하고 되쏘면 된다
- **메시지 수정/삭제** — 오타를 고치면 번역도 다시 돌려야 한다

## 번역을 더 좋게

- **단어장** — 설명에 나온 표현을 저장해 두고 나중에 복습. 설명 기능이 생겼으니
  다음 단계는 그걸 모아두는 것
- **작성 중 도움** — 스페인어로 써보려다 막혔을 때, 한국어로 쓴 초안을 스페인어로 고쳐 주고
  왜 그렇게 되는지 알려주기. 번역의 반대 방향

## 운영

- **백업** — SQLite 파일 하나라 `cp` 로 끝나지만, 자동으로 돌려두면 마음이 편하다
- **대화 내보내기** — 몇 년 치가 쌓이면 한 번쯤 꺼내 보고 싶어진다
- **테스트** — 번역 파이프라인(모델 호출을 가짜로 대체)과 인증에 테스트가 아직 없다

## 나중에

- **음성 메시지** — 받아쓰기 → 번역 → 읽어주기. 발음 공부에 직접적으로 도움이 된다
- **네이티브 앱** — 알림과 백그라운드 동작이 답답해지면 Expo로 옮기는 게 다음 단계.
  서버와 `shared/` 는 그대로 쓸 수 있다
